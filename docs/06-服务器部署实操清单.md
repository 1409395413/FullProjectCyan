## 0. 端口放行情况（已实测，无需再配）

从本地对 `8.138.93.141` 做 TCP 探测的结果：

| 端口 | 结果 | 含义 |
|---|---|---|
| 22 | ✅ 连通 | SSH 已放行 |
| 80 | ✅ 连通 | HTTP 已放行，站点可访问 |
| 443 | ⚠️ **Connection refused** | **安全组已经放行**（包到了主机，是内核回的 RST，因为没有进程在听 443），等 certbot 跑完 nginx 一监听就能用 |

> refusd 和 timeout 要分清楚：timeout = 安全组丢包没放行；refused = 放行了的，只是还没人监听。
> 所以**不用再去控制台加 443 规则**。

> ⚠️ **备案提醒**：国内节点用**域名**对外访问必须先备案，否则 80/443 会被阿里云拦截（返回
> `Non-compliance ICP Filing` 403 页）。未备案阶段用 `http://8.138.93.141` 按 IP 访问。

## 3. 解压

```bash
sudo mkdir -p /opt/portfolio
sudo tar -xzf /opt/deploy.tar.gz -C /opt/portfolio
ls /opt/portfolio             # 应看到 app.jar、web/、deploy/、db/、config/、scripts/
```

> 包是 `tar.gz` 不是 zip：Windows 的 `Compress-Archive` 会在 zip 里写**反斜杠**路径
> （`deploy\nginx.conf`），Linux 上反斜杠是合法文件名字符，解压后不建目录、
> 只得到一堆带反斜杠的扁平文件，整个目录结构丢失、部署直接跑不起来。
> 这个坑在 Windows 上验证不出来（Python 的 zipfile 会把 `\` 规范化成 `/`）。

## 4. 安装依赖（自动完成 2 GiB 机型调优）

```bash
cd /opt/portfolio && bash setup-ubuntu.sh --install-deps
```

这一条命令会做（耗时几分钟）：

- 安装 `openjdk-17-jre-headless`、`mysql-server`、`redis-server`、`nginx`
- **创建 2 GiB swap 并写入 /etc/fstab** —— 2 GiB 内存跑 MySQL 8 + JVM + Redis 很紧，
  没有 swap 时内核 OOM Killer 会随机杀进程（通常是把 MySQL 杀掉，表现是后端突然连不上库）
- **写入 MySQL 小内存配置** `/etc/mysql/conf.d/portfolio-small.cnf`
  （`innodb_buffer_pool_size=192M`、`max_connections=60`），并重启 MySQL
- 创建系统用户 `portfolio`、建 `/var/lib/portfolio/upload` 与 `/var/log/portfolio` 并设好属主
- 注册 systemd 单元、安装 nginx 配置（**此时不会启动后端**，因为密钥还没填）

## 6. 生成密钥并填写环境变量

```bash
cd /opt/portfolio/deploy
cp env.production.example portfolio.env
chmod 600 portfolio.env

MYSQL_PW=$(openssl rand -hex 16)
REDIS_PW=$(openssl rand -hex 16)
JWT=$(openssl rand -hex 32)
ADMIN_PW=$(openssl rand -hex 8)

sudo mysql -e "CREATE USER IF NOT EXISTS 'Cyan'@'%' IDENTIFIED BY '$MYSQL_PW';"
sudo mysql -e "GRANT ALL PRIVILEGES ON CyanWorks.* TO 'Cyan'@'%'; FLUSH PRIVILEGES;"

sed -i "s|^MYSQL_HOST=.*|MYSQL_HOST=127.0.0.1|"      portfolio.env
sed -i "s|^MYSQL_PORT=.*|MYSQL_PORT=3306|"           portfolio.env
sed -i "s|^MYSQL_DB=.*|MYSQL_DB=CyanWorks|"               portfolio.env
sed -i "s|^MYSQL_USER=.*|MYSQL_USER=Cyan|"         portfolio.env
sed -i "s|^MYSQL_PASSWORD=.*|MYSQL_PASSWORD=$MYSQL_PW|" portfolio.env
sed -i "s|^REDIS_PASSWORD=.*|REDIS_PASSWORD=$REDIS_PW|" portfolio.env
sed -i "s|^JWT_SECRET=.*|JWT_SECRET=$JWT|"           portfolio.env
sed -i "s|^ADMIN_USERNAME=.*|ADMIN_USERNAME=Cyan|"   portfolio.env
sed -i "s|^ADMIN_PASSWORD=.*|ADMIN_PASSWORD=$ADMIN_PW|" portfolio.env
sed -i "s|^APP_UPLOAD_DIR=.*|APP_UPLOAD_DIR=/var/lib/portfolio/upload|" portfolio.env
sed -i "s|^APP_CORS_ORIGINS=.*|APP_CORS_ORIGINS=http://8.138.93.141|" portfolio.env

echo "=============================="
echo "后台管理员：Cyan / $ADMIN_PW"
echo "=============================="
```

## 10. 备案通过后：完整操作清单

按顺序做，一共 6 步。前 5 步是我这边一条命令的事，第 6 步必须你自己在后台改。

### ① 补根域名解析（你要做）
备案通过后，去云解析 DNS 给 `cyaniam.online` 加一条 **主机记录 `@`** 的 A 记录 → `8.138.93.141`。
`www` 那条你已经配好并验证生效了，只差根域名。

### ② 确认解析生效
```bash
nslookup cyaniam.online        # 应返回 8.138.93.141
curl -I http://cyaniam.online  # 应返回 200，不再是备案拦截页
```
刚加完记录一般几分钟内生效，最迟 10 分钟。

### ③ 开 HTTPS（我来做）
certbot 1.21.0 已预装，`certbot.timer` 已启用（证书到期自动续）。一条命令：

```bash
certbot --nginx -d cyaniam.online -d www.cyaniam.online --redirect -m 你的邮箱 --agree-tos
nginx -t && systemctl reload nginx
```
`--nginx` 插件会自动改写 `/etc/nginx/conf.d/portfolio.conf`：加 443、挂证书、80 强制跳 HTTPS。
443 端口我实测过是 `ConnectionRefused`（= 安全组已放行、只是没人监听），不用去控制台加规则。

### ④ 更新 CORS 白名单（我来做）
```bash
sed -i 's|^APP_CORS_ORIGINS=.*|APP_CORS_ORIGINS=https://cyaniam.online,https://www.cyaniam.online|' \
    /opt/portfolio/deploy/portfolio.env
systemctl restart portfolio
```

### ⑤ 冒烟验收（我来做）
域名首页 200 / 后台 200 / `https://` 小绿锁 / 上传一张图 → `/media/...` 直出 200 / 无console报错。

### ⑥ 把备案号放进网站页脚（**必须你做，这是管局硬性要求**）
备案通过后会拿到 `粤ICP备xxxxxxxx号`。个人备案的网站必须在**页脚展示备案号并链接到工信部**，
管局会抽查，不挂可能被注销备案。

进 `http://8.138.93.141/login` → 后台改页脚文案，形如：

```html
© 2026 Cyan · Studio. <a href="https://beian.miit.gov.cn/" target="_blank" rel="noopener">粤ICP备xxxxxxxx号</a>
```

后台「站点设置」里已内置 **ICP 备案号 / 公安备案号** 两个输入框和 **显示备案信息** 开关，直接填号即可，不用手写 HTML。

> 另外还有个容易漏的：**公安备案**——网站上线后 30 日内，到
> `beian.mps.gov.cn`（全国互联网安全管理服务平台）提交。跟 ICP 备案是两套，不冲突。

## 11. 备案通过后：开 HTTPS

certbot 1.21.0 已经装好了（`certbot.timer` 也已启用，证书会自动续期），
所以备案一下来，只需这一条命令：

```bash
certbot --nginx -d cyaniam.online -d www.cyaniam.online --redirect -m 你的邮箱 --agree-tos
nginx -t && systemctl reload nginx
```

`--nginx` 插件会自动改写 `/etc/nginx/conf.d/portfolio.conf`：加 443 监听、
挂 `/etc/letsencrypt/live/cyaniam.online/` 的证书、把 80 强制跳 HTTPS。**不用手工替换配置**。

然后别忘了把域名加进 CORS 白名单：

```bash
sed -i 's|^APP_CORS_ORIGINS=.*|APP_CORS_ORIGINS=https://cyaniam.online,https://www.cyaniam.online|' \
    /opt/portfolio/deploy/portfolio.env
systemctl restart portfolio
```

> `certbot --nginx` 靠 `server_name` 匹配 server 块，所以之前把 nginx 的
> `server_name` 从通配的 `_` 改成了具体域名 —— 写 `_` 的话 certbot 匹配不到。

## 2 GiB 机型的注意事项

| 事项 | 说明 |
|---|---|
| 内存 | JVM 堆上限 512 MB、systemd 限 1 GiB；MySQL 缓冲池 192 MB。预留的 2 GiB swap 是安全垫 |
| 别再装别的 | 这台机器只有 2 GiB，不建议再跑其他服务 |
| 上传大视频 | nginx `client_max_body_size` 是 220m；后端单次上限 200 MB，超过会失败 |
| 后台传完素材不显示 | Redis 缓存 TTL 300 秒，等 5 分钟或 `redis-cli -a 密码 FLUSHDB` |
| 日常备份 | `bash /opt/portfolio/scripts/backup-ubuntu.sh /var/backups/portfolio`，建议加 crontab 每天 03:00 |

## 出问题先看这里

| 现象 | 排查 |
|---|---|
| 502 Bad Gateway | 后端没起来：`journalctl -u portfolio -n 100`，多半是密码不对或端口写错 |
| 后端启动即连不上库 | 检查 `--apply-secrets` 是否跑过、`MYSQL_PORT` 是否 3306 |
| 素材 404 | `APP_UPLOAD_DIR` 与 nginx `/media/` alias 不一致，或目录属主不是 portfolio |
| Redis 起不来 | ① 用了 Docker 版 `deploy/redis.conf`（`dir /data` 裸机不存在），必须用 `--apply-secrets` 走裸机配置；② `bind` 不要写 `127.0.0.1 -::1`，无 IPv6 的机器上 Redis 6.0 会直接退出 |
| 后端无限重启、YAML 报错 | `/opt/portfolio/config/application.yml` 会被 Spring 加载且优先级高于 jar 内配置。参考配置必须叫 `application.yml.example` |
| 内存吃满被杀 | `dmesg | grep -i oom`，确认 swap 生效；必要时把 `-Xmx512m` 再调小 |
